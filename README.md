# Aprendiendo-Machine-Learning
Mi progreso aprendiendo Machine Learning con Python mediante ejercicios y pequeños proyectos.

¿Qué vas a encontrar?

- Ejercicios de Python
- Prácticas con Pandas y NumPy

- Proyectos personales

Mi objetivo

Aprender Machine Learning desde cero, entender cómo funcionan los modelos y, con el tiempo, desarrollar proyectos cada vez más completos.

Estado

Voy actualizando este repositorio a medida que aprendo cosas nuevas.
